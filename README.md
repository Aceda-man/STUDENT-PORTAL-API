Student Portal API
Adegboyega Adeyemi

BAD/2026/TC-8/0108

A REST API for students to create and manage their own accounts. Built with Express and MongoDB (Mongoose).

Features
Create a student account (name, registration number, email)
Retrieve a student's details by ID
Update a student's name only — registration number and email are immutable after creation
Delete a student's account permanently

Tech Stack
Node.js / Express
MongoDB with Mongoose
